# Photos

Put photos here named after the place `id` in `js/places.js`:

| File | Shown as |
|---|---|
| `<id>.jpg` | Building photo (taken from where a fresher would approach it) |
| `<id>-entrance.jpg` | Close-up of the door / staircase people should use |

Example: `it-faculty.jpg`, `it-faculty-entrance.jpg`, `library.jpg`.

Tips: landscape, roughly 1600×1000, under ~300 KB each (squash with https://squoosh.app).
Places with no photo just show "Photo coming soon".
